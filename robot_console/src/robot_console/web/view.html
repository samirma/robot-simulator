Changes are sent to the robot immediately, and only base motion is stopped automatically. Sliders, the head pad and the model's joints send while you drag, a typed number when you commit it (Enter or leaving the field), and service and action-group buttons once per click. An action control sends goals as you drag where its action server preempts the running goal; elsewhere it keeps one goal at a time, your latest change goes out when that goal ends, and a goal the server refuses is shown as rejected. ‘Read measured’ asks the robot for its measured positions once per click; where the profile documents a read-only position query, the page asks it about once a second after validation (it commands nothing). For these controls, leaving, reloading or closing this page and a lost connection send nothing: a running goal keeps running. A mobile robot's base motion (beside the cameras) is hold-to-move, as in teleop.sh, and is stopped on release, Space, its Stop button, focus loss, page hide and a target change.
